🚀 About the Project

This project recreates the design philosophy behind Apple’s product pages, which emphasize:

Clean and elegant layouts

Strong typography

Minimalistic user interfaces

Responsive design across devices

The main goal of this project is to improve frontend development skills by replicating real-world UI patterns using modern development tools and workflows.

🧰 Tech Stack
Core Technologies

HTML5

CSS3

JavaScript (ES6+)

Frameworks & Tools

Vite — fast development and build tool

Tailwind CSS — utility-first styling approach

PostCSS — CSS processing pipeline

ESLint — maintains code quality and consistency

Deployment

Netlify

🔥 Features

✔ Apple-inspired modern UI
✔ Fully responsive layout (desktop, tablet, mobile)
✔ Fast development workflow using Vite
✔ Utility-first styling with Tailwind CSS
✔ Clean and organized project structure
✔ Deployed live for easy preview

🎯 Learning Objectives

This project was created to practice and strengthen:

Real-world UI replication

Modern frontend tooling and workflow

Responsive design techniques

Efficient styling with Tailwind CSS

Clean and scalable frontend architecture
